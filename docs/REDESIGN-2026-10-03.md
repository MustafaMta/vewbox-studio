software. Vewbox must combine three experiences in one identity: premium entertainment presentation, a professional

takes → assembly, and a shot workspace with a prominent preview, character/location/reference selection, shot
description, camera and action controls, generation settings behind progressive disclosure (never a node editor or
ComfyUI internals), status, takes, approval, regeneration and continuation. The Creative Director holds the

reviews all prototypes before implementation. Generation stays paused.

### Change of requirement: English-only interface (producer, 2026-10-03)

The website is English-only and always left-to-right: no Arabic localization, no RTL layouts, no direction
switching, no Arabic numeral setting — on every page, dialog and creation flow. This is not English-only filmmaking:
scripts, dialogue, names, lyrics, subtitles, voices and films stay multilingual (Iraqi Arabic first), and every piece
of user-authored or generated content in another language is preserved and rendered in its own direction, isolated,
inside the English interface. Applied:

|---|---|
| `docs/DESIGN-SYSTEM-V5.md` | notice at the top; §9 rewritten as "Content in other languages" (content faces, one isolated content rule, Western numerals by kind, what is removed); acceptance gate English-only plus a content check per page |
| DS-1 (running) | told immediately: no RTL rules, no numerals setting, English-only strings in new files, F2/N3 dropped; F1 and F3 kept; Arabic content faces and the content rule kept |
| Prototypes | the 48 Arabic renders removed from `docs/evidence/redesign-proto/` (history keeps them); the prototypes' `?lang=ar` switch is obsolete and not maintained |

### Final requirement: a completely English-only website (producer, 2026-10-03)

Replaces the previous section's softer plan: one website language; no Arabic interface, RTL mode, language selector
or preference, numeral setting, translation dictionaries, language-specific UI routes, Arabic design tokens,
components, prototypes or tests, and no localization infrastructure kept for later. No language-specific interface
fonts: only Newsreader, IBM Plex Sans and IBM Plex Mono load; Arabic film content renders through the system's Arabic
font in the fallback chain, isolated with `dir="auto"` (correct text rendering, not an RTL website). Film languages
are untouched: Iraqi Arabic dialogue, scripts, names, lyrics, voices, subtitles and all production data stay.

Work: DS-1 (running) drops the Arabic fonts, fixes `<html lang="en" dir="ltr">`, Western digits only, English-only
captures. EN-1 (new, worktree, database copy `vewbox_en`, server :4242) removes the multilingual layer: Arabic strings
and the locale machinery (the string system collapses to a plain English copy module that page packages replace with

Arabic halves, RTL-only CSS, language options in capture scripts, multilingual UI tests — verifying each removal
against production use; content-language production logic stays. Both merge before DS-2 and the pages start.
