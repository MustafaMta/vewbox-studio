## 1. Chatterbox Multilingual V3 (A)

- **Repos.** Weights: `ResembleAI/chatterbox` (one repo holds English, Multilingual v2 and v3). Code: `github.com/resemble-ai/chatterbox` master; v3 release commit `65b18437` (2026-06-10), latest `5de7a54a` (2026-07-21); package `chatterbox-tts` 0.1.7. V3 T3 weights were uploaded 2026-04-22 (`e2d6902d`), S3Gen v3 2026-06-10.
- **Languages.** 23 codes incl. `ar` and `en` (`SUPPORTED_LANGUAGES`); `language_id` is required and prepended as a `[ar]` token. Blog (2026-06-10): Arabic CER sits in the 6–8 % bucket (*self*, transcription-based); training mixture 25.6k → 36.7k h; v3 "improves voice identity and accent preservation across languages", fewer hallucinations — **no numbers published**.
- **Architecture (from source).** `T3` = HF `LlamaModel` "Llama_520M": 30 layers, hidden 1024, 16 heads (head_dim 64), MLP 4096, llama3 RoPE; `text_emb` 2454×1024, `speech_emb` 8194×1024, learned `text_pos_emb`/`speech_pos_emb`, `text_head`, `speech_head`; `cond_enc` = `spkr_enc` (Linear 256→1024 on the voice-encoder embedding) + `emotion_adv_fc` (Linear 1→1024 = exaggeration) + `Perceiver` resampler over 150 prompt speech tokens (6 s). **536 M params** (file bytes/4, fp32). `S3Gen` (CosyVoice-derived, Apache-2.0 code): `S3Tokenizer` "speech_tokenizer_v2_25hz" (16 kHz, 25 tokens/s, vocab 6561), `CAMPPlus` x-vector, `UpsampleConformerEncoder` (6×512), `CausalConditionalCFM` flow matching (10 steps), `HiFTGenerator` vocoder → **24 kHz**; 264 M params. `VoiceEncoder`: 3-layer LSTM on mels → 256-d; 1.4 M params. `perth.PerthImplicitWatermarker` is applied to every `generate()` output (detector returns 0/1).
- **Controls** (`generate` defaults): `exaggeration` 0.5 (Space slider 0.25–2), `cfg_weight` 0.5 (`logits = cond + w·(cond − uncond)`; 0 disables CFG), `temperature` 0.8, `repetition_penalty` 1.2, `min_p` 0.05, `top_p` 1.0, `max_new_tokens` 1000 (= 40 s). Reference: 6 s @16 kHz for prompt tokens, 10 s @24 kHz for S3Gen (longer is truncated); Resemble recommends ≥ 10 s.
- **Tokenizer.** `MTLTokenizer`: lowercase + NFKD (أ → ا+ٔ, both in vocab), spaces → `[SPACE]`, no merges for Arabic (249 single-character Arabic-block tokens). An undocumented `[ipa]` token exists.
- **Deps** (pyproject 0.1.7): torch/torchaudio 2.6.0, transformers 5.2.0, librosa 0.11.0, diffusers 0.29.0, safetensors 0.5.3, conformer 0.3.2, s3tokenizer (unpinned), resemble-perth (git master; Space pins 1.0.1).
- **RTX 5090 / VRAM / RTF.** NVIDIA NVIGI card: ≈ 3.5 GB VRAM for Multilingual; faster than real time. Resemble: TTFB < 300 ms on H100 (*self*). Issue #344: a 5090 user reports 1–2 s per sentence at ≈ 30 % utilisation (unoptimised). Independent same-language Arabic benchmark (soniqo, 2026-07-02, FLEURS `ar_eg`, fp16): speaker cosine 0.703, WER 28.3 % (human floor 32.8 %), UTMOS 2.90, RTF 1.10 on unnamed hardware. **Expect RTF ≈ 0.3–1 unoptimised; measure on the 5090.**

## 2. Fine-tuning (B)

- **Official:** no training script; `T3.loss()` returns text CE + speech CE (targets: S3 tokens). All recipes below are community engineering references.
- **Data pipeline (what the code needs):** wav → 16 kHz for `s3gen.tokenizer` (S3 tokens) and `ve` embedding, 24 kHz mel + CAMPPlus x-vector for S3Gen refs; text through `MTLTokenizer` with `[ar]`; `speech_cond_prompt_len` 150 tokens; `emotion_adv` 0.5. Formats in the wild: `wavs/` + `metadata.csv` (`file_name|transcription`), 3–10 s segments optimal (gokhaneraslan), 1–400 s accepted (Ahmed-Ezzat20), any sample rate (resampled).
- **LoRA recipes that worked:** Praxy Voice (arXiv 2604.25441): PEFT LoRA r32/α64/dropout 0.05 on `q_proj,k_proj,v_proj,o_proj` of T3 (7.86 M params), `s3gen`+`ve` frozen, AdamW β(0.9,0.95) wd 0.01, **peak lr 3e-6 cosine, 500 warm-up** (2e-5 diverged at step 3.6k), batch 16, grad-clip 0.5, 8,000 steps, A100 11 h. reenigne314 Indic LoRA: same targets, 7.8 M/544 M, vocab extended 2454→2871 with warm-started rows and **gradient masking of original embedding rows**, weighted sampling across rounds — no catastrophic forgetting (Hindi CER improved), S3Gen/VE frozen; CER-only evaluation. Ahmed-Ezzat20: LoRA on q/k/v/o/gate/up/down, lr 2e-5, 50 epochs, batch 1×8.
- **Full/partial T3 FT:** Singlish (arXiv 2607.23027): full T3, S3Gen+VE frozen, lr 1e-5, batch 16, 100 epochs, 55.5 h/50 speakers → SPK-SIM **rose** 0.724→0.791 (in-domain) and 0.688→0.746 (unseen speakers), accent-SIM up, WER 11.5→15.4 %, UTMOS 3.34→2.75. AliAbdallah21 Egyptian (120 h, one speaker, lr 1e-5, batch 2×8, 3 epochs, 24 kHz): advertised as "freeze early acoustic / unfreeze prosody", but `train.py` matches names `decoder|dec_layer|duration|prosody|pitch` that **do not exist in T3** — it is full-T3 FT minus `text_emb` (99.53 % trainable), loss = speech + 0.1·text; author judged checkpoint-2000 best and later ones robotic (overfit); its LoRA-vs-full claim is informal.
- **Vewbox-IQ v1 (modules named from `t3.py`/`cond_enc.py`):**
  - Stage A (LoRA, ≈ 10 h data): `t3.tfmr.layers.{0..29}.self_attn.{q,k,v,o}_proj` + `.mlp.{gate,up,down}_proj`, r32/α64; `t3.text_emb` trainable for Arabic-block rows only (gradient mask); lr 3e-6 cosine, 500 warm-up, bf16, batch 16 (grad-accum), grad-clip 0.5, 20–30 % replay of English + MSA to protect `[en]` and MSA.
  - Stage B (partial FT, ≥ 20 h multi-speaker): merge LoRA, unfreeze `t3.tfmr.layers.18–29` fully and `t3.text_emb` (Arabic rows); lr 1e-5 linear decay; stop by held-out ECAPA SIM (no drop > 0.03 vs base) and English CER (no regression), checkpoint every 500 steps, keep the earliest acceptable.
  - Frozen in both: `ve.*`, `s3gen.*` (tokenizer, `speaker_encoder` CAMPPlus, `flow`, `mel2wav`), `t3.cond_enc.spkr_enc`, `t3.cond_enc.perceiver`, `t3.cond_enc.emotion_adv_fc`, `t3.speech_emb`, `t3.speech_head`, `t3.*_pos_emb`. Rationale: identity enters T3 only through `cond_enc`; S3 token semantics live in `speech_emb/speech_head`; S3Gen reproduces timbre from the reference x-vector.
  - Pitfalls: single-speaker data collapses identity (Egyptian corpus) → ≥ 3 speakers; loss ≠ quality (ear decides); watermark is applied at inference by `perth`, training is unaffected; keep `t3_model` loading on the v3 file, not the v2 default.

## 3. Data (C)

- **Kharrufa corpus:** GitHub `hayderkharrufa/iraqi-dialect-tts-corpus` (README, `LICENSE` = CC BY 4.0 text, `CITATION.cff`, `resources/`); data = Drive zip `1iQ-ueye2pLFavy-2HWDEOhscD_wn_7ie` ("iraqi-dialect-tts-corpus.zip"); baseline model = FastPitch via `tts-arabic-pytorch` (Drive). Zenodo 11170567 (2024-05-10) holds only the paper PDF (653 kB): built on Halabi's Arabic Speech Corpus (CC BY 4.0, one Damascene MSA speaker, 1,813 utterances, phoneme TextGrids, Buckwalter) plus custom Iraqi recordings; speaker count, sample rate and utterance count are **not published online** (read the PDF offline before mirroring). Phonetic annotation uses an extended Buckwalter: `C`=چ, `G`=گ, `P`=پ, `V`=ڤ, plus ı/L/O/ێ.
- **Other Iraqi speech with training rights:** `facebook/omnilingual-asr-corpus` (CC-BY-4.0): `acm_Arab` 596 rows, `ayp_Arab` 900/300/300 (Habibi drew 11.7 h Iraqi from it) — multi-speaker, ASR-grade. Nothing else: HF `xtz999/iraqi_arabic_speech_youssef` (3,867 clips, 22.05 kHz, 720 MB), `safaa94/Myvoice-iraqi-accent-samples`, `karimBD/…MediaSpeech` carry **no licence**; `otozz/iraqi_train_set` (12,564 ex., CC BY 4.0 label) is a Whisper-feature repack of YouTube-crawled MASC (1,000 h, IEEE DataPort, dialect field, no stated licence); LDC2006S45 (≈ 50 h, 474 speakers, 8 kHz a-law telephone, LDC fee licence); Common Voice ar (CC0) has no dialect tag; MGB-3/5 (Egyptian/Moroccan), SADA (Saudi, NC), Casablanca and SawtArabi (no Iraqi). **Licensed Iraqi audio available today ≈ 1 h studio + ≈ 12 h ASR-grade.** The studio recording (Baghdadi actors, 48 kHz master → 24 kHz, 3–15 s lines, pronounced spelling, ≥ 3 speakers, ≥ 10 h) is the production dataset; Kharrufa + Omnilingual are warm-up/eval.

## 4. Baghdadi phonology and frontend (D)

- **Consonants (Muslim Baghdadi):** b t tˤ d k g ʔ; tʃ dʒ; f θ ð ðˤ s sˤ z ʃ x ɣ ħ ʕ h; m n; ɾ(r) l ɫ w j; marginal p v q (Persian/Turkish loans and learned words). **Vowels:** ɪ u ə æ (short); iː uː eː oː aː (long); *aj* → eː (lēš), *aw* → oː (kōn). ض/ظ merge in ðˤ; interdentals retained; ʕ with glottal closure.
- **Reflexes that decide spelling:** ق → **g** in Muslim Baghdadi (gāl, gumar, gahwe; occasionally dʒ: jiddām), **q kept** in learned/MSA and loan words (ḥaqīqa); Christian and Jewish Baghdadi (qeltu) keep q. ك → **tʃ** mainly next to original /i/ (čalib < kalb, čān < kāna; 2fs suffix -ič — confirm against Erwin 1963). ج = dʒ. Loans: پ/ڤ may merge to b/f for some speakers. (Sources: Wikipedia "Baghdadi Arabic", "Varieties of Arabic" qāf table, Wiktionary چلب; Erwin, *A Short Reference Grammar of Iraqi Arabic*, 1963; Blanc 1964.)
- **Vewbox-IQ phoneme inventory (annotation standard, IPA):** /b t tˤ d k g q ʔ tʃ dʒ f v θ ð ðˤ s sˤ z ʃ x ɣ ħ ʕ h m n r l ɫ w j p/ + /ɪ u ə æ iː uː eː oː aː/ + gemination mark. Represented in Arabic script for the model: one letter per phoneme — گ=g, چ=tʃ, پ=p, ڤ=v, ق=q only where pronounced, ك=k, ج=dʒ, short vowels by tashkeel only where ambiguous.
- **G2P tools and limits:** Mishkal (rule/dictionary MSA diacritiser, last release 2021), CAMeL Tools (morphology/disambiguation DBs for **MSA and EGY only**, GPL v2; dialect-ID 25 cities; no Iraqi morphology, no diacritiser package), espeak-ng `ar` (needs fully diacritised MSA), DialG2P (Egyptian), arbtok (claims Mosul qeltu; unverified), Kharrufa phonetiser (CC BY-NC). None models Baghdadi ق/ك reflexes → **no G2P in the pipeline**; grapheme input + a studio Baghdadi lexicon (ق→g/q, ك→č words) applied as a spelling pass, reviewed by the native reader.

## 5. Cross-language speaker preservation (E)

- Mechanism: identity reaches T3 only via the 256-d voice-encoder embedding + 6 s of prompt speech tokens; S3Gen takes the x-vector + 10 s reference mel. Resemble's own guidance: the **reference clip must match the language tag**, otherwise "language transfer outputs may inherit the accent of the reference clip's language"; mitigation `cfg_weight=0`.
- Evidence: Praxy Voice — a 49 s cross-language English reference raised FAD ≈ 26 % on Telugu vs a same-language 8–11 s reference. IWSLT 2026 CLVC (Ahtasam et al.): Arabic "particularly challenging"; KIT on Fish S2 Pro EN→AR SSIM 64 %. Singlish: full T3 FT with S3Gen/VE frozen **raised** SPK-SIM, so T3 adaptation need not cost identity when the speaker path is frozen. Resemble claims v3 holds identity across language switches (no figures).
- Design: per character record **two references from the same actor** (Baghdadi line, English line), each ≤ 10 s, clean; generate `[ar]` with the Arabic reference and `[en]` with the English one; ECAPA cross-check every take against both references (≥ 0.80 same-language, report cross-language); the native listener's "same person" verdict stays the gate.

## 6. Risks

| Risk | Mitigation |
|---|---|
| `s3gen_v3` undocumented pairing | default `s3gen.pt`; A/B by ear; pin both |
| torch 2.6.0 pin vs sm_120 | cu128 torch first, `--no-deps`; document stack in `docker/` |
| Only ≈ 1 h licensed studio Iraqi audio | own recording is the real dataset; Kharrufa/Omnilingual for warm-up |
| Identity collapse / forgetting | freeze speaker path, multi-speaker data, EN+MSA replay, SIM/CER stop rule |
| ق/ك ambiguity in written Iraqi | pronounced spelling + lexicon; native review |
| Watermark in all outputs | accepted (MIT, detector available); note in deliverables |
| v3 claims unmeasured for Arabic | measure baseline (SIM, CER, UTMOS) before any training |
